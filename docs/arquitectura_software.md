## 🏗️ Arquitectura General

El sistema sigue una arquitectura modular compuesta por:

| Componente | Tecnología | Responsabilidad |
|---|---|---|
| Frontend | React + Vite | Interfaz de usuario e interacción con el operador |
| Backend principal | Node.js | Orquestación de servicios y exposición de API REST |
| Microservicios | Go | Procesamiento de alta concurrencia y bajo consumo de recursos |
| Procesamiento de datos | Python + Pandas | Análisis, limpieza y transformación de métricas |
| Persistencia | SQLite | Almacenamiento local ligero para entornos de prueba/demo |
